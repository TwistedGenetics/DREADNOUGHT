# DREADNOUGHT host scenario (0.27): chords in the sequencer. On FM (and SAMPLER's keys, and MIDI), keys pressed while
# another is held go into its step as a chord: the lowest note the step's, the others a shape of distances (one of the
# project's 15). The chord plays back, moves with the step's note, and is kept with the patterns.
# White keys (tracks 1..8): 0 2 4 6 7 9 11 12. Keys from 0 (F3 = 53): 0 F3, 4 A3, 7 C4, 11 E4.
sysex 76 6 7 0

tap SEQ

expect trk 7

wait 1200
key 20 up
expect on.7 0
tap SEQ
expect page 0

tap REC
expect rec 1
key 0 down
wait 30
key 4 down
wait 30
key 7 down
wait 30
key 7 up
key 4 up
key 0 up
wait 30
expect on.7 1
expect nt.7.1 53
expect chordof.7.1 1
expect chord.1.0 4
expect chord.1.1 7
expect chord.1.2 0
# the next step: a single note (all keys were up)
tapkey 11 40
expect on.7 2
expect nt.7.2 64
expect chordof.7.2 0

wait 30

key 4 up
key 7 up
