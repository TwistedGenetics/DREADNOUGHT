# tests/host/saves/vX.bin is the flash objects of that release's simulator after: the project named JAMIE, track 2's
# send A 100, track 4 to SUB, REESE's 4th factory sound, track 1 on its 3rd pattern, SAVE. Before 0.20.1 a save from

# 0.23: SAMPLER's settings went into the SONG object (layout 2, "DNS2"). A 0.22 save (tests/host/saves/v0.22.bin:
